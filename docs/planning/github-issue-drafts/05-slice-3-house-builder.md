## What to build

Build Brick's House Builder: construct three houses by selecting or dragging parts in order, snap correct pieces, bounce wrong pieces back, score by hints/attempts, and unlock a sticker.

## Acceptance criteria

- [ ] Blueprint/order data is test-covered.
- [ ] Part tray and snap-zone interaction supports touch and keyboard-accessible selection path.
- [ ] Wrong pieces bounce back without failure language.
- [ ] Three houses can be built from start to completion.
- [ ] Sticker unlock persists to the selected profile.
- [ ] House-part asset needs are recorded in the asset backlog.

## Blocked by

Slice 1 and house-part placeholders.
